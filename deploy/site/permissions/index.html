权限说明

更新：2026-10-06 · 当前版本 0.1.0

相机

开启二维码/条码扫描时才申请。拒绝后仍可生成二维码或选择图片识别，可在系统权限设置撤回。相机为可选硬件。

网络与网络状态

用于目录、账号、同步、公告推荐、反馈、AI、网页版和网络诊断。同步默认关闭，AI 发送前单独同意。网络状态权限查询连接可用性，不提供位置访问。

文件访问

系统图片/文档选择器授予所选文件访问权；保存位置由你选择，分享只授予临时 URI 访问。无需全盘存储权限。

其他

未申请位置、麦克风、通讯录、电话或全盘存储权限。联系人/日历/Wi-Fi 二维码由其他应用导入。AndroidX 应用内签名权限用于保护接收器。

English

Permissions

Camera access is requested only when starting QR/barcode scanning. Generation and image selection work without it. Internet access supports catalog, accounts, sync, feedback, AI, web tools and diagnostics. Sync is off by default; AI requires separate consent. Network state checks connectivity. System pickers grant access only to selected files, and sharing uses temporary URI grants. No location, microphone, contacts, phone or broad storage access is requested. AndroidX’s signature permission protects app-internal receivers.
