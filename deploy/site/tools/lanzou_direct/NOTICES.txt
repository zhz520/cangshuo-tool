沧烁工具箱 - 蓝奏直链解析

The deterministic acw_sc__v2 download handshake and the current Lanzou page
field mapping were informed by these MIT-licensed projects:

- hanximeng/LanzouAPI, commit eb2d2eb25233d7e44645162e4f817abc0ec87d94
  https://github.com/hanximeng/LanzouAPI
- WhY15w/lanzou, commit 437b7d0389e9900e38770991da2d5506138f64fe
  https://github.com/WhY15w/lanzou

The server implementation is an independent Java adaptation. It does not
proxy files, rotate client IP addresses, submit forged forwarding headers, or
bypass an interactive captcha. Unsupported interactive verification returns an
official-page fallback.
