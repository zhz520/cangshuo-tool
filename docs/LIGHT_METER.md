# 光感仪

唯一 code：`light_meter`；SENSOR / LOCAL，排序 340。Android 通过 UI → ViewModel → ObserveLightUseCase → SensorLightMeterRepository → 已有 SensorsRepository 获取光线传感器值。没有相机、位置或存储权限，没有测量数据上传。

## 功能与规则

- 实时照度，lx 与 fc 切换。1 fc = 1 / 0.3048² lx；同时显示环境参考分级。分级只用于粗略描述明暗，不是照明标准或健康建议。
- 本次测量样本数、最小、最大、平均值。平均按接收的有效样本计算，不是按时间加权；统计从打开或清空记录开始，暂停与后台期间不计入。
- 趋势支持 15/30/60 秒窗口，以最后读数时间为截止点；保留最近 600 个样本、最多每 100ms 接收一次。静止光线可能没有新的传感器回调，不补造周期样本。横轴按单调时间比例绘制，平值或单点可正常显示。
- 暂停持有最后有效值并注销监听，继续重新注册；清空记录只清空统计与趋势，保留当前读数和校准系数。
- 输入专业参考仪表的 lx 值，按 reference / raw 计算校准系数，允许 0.1–10；全体显示与统计按同一系数换算，原始数据不变。不把上一次已校准值作为下一次校准的分母。
- 参考输入最多 16 字符、10 位整数、4 位小数，支持小数点或小数逗号，拒绝科学计数、千分位、负值、0、非有限数和超过 10⁹ 的值。没有正读数、等待恢复或无效数据时不允许校准。失败保留原输入与系数。
- 选择测量摘要或趋势 CSV 后可复制、系统分享。CSV 稳定列为 `elapsed_s,raw_lux,corrected_lux`，秒数相对第一条记录，与显示单位无关，最多 600 行；摘要包含当前单位、统计、校准、原值、状态与硬件名称。
- 中文和英语资源对应，主题强调色和深浅色沿用共享组件。趋势图放入 `core/ui/ToolboxTrendChart`，支持可访问描述；页面可滚动，窄屏和大字号结果使用共享响应式行。

## 生命周期、异常和资源边界

- 仅前台订阅；stop、暂停、返回、ViewModel 清理取消 Flow，由既有 callbackFlow 的 awaitClose 注销 SensorEventListener。重复 start 不建立额外监听，旧任务通过取消和 generation 排除。
- 首次有效读数有 5 秒预算，超时显示明确状态并注销监听，刷新可重试。第一次有效读数后，TYPE_LIGHT 的 on-change 静默不当作超时。
- 无光线传感器与注册/读取失败分开提示。负值、NaN、Infinity、超过 10⁹ lx 或无有效时间戳的样本不参与统计；重复时间不重复计数，乱序事件不回退当前值。
- 接近或达到硬件最大量程显示饱和提示，不声称读到了真实更高照度。传感器厂商、分辨率、量程直接来自真实硬件。
- 原始样本和统计只在内存，不进 Room、服务端或日志。单位、参考文本、校准和窗口通过 SavedStateHandle 保留当前工具会话；不承诺跨会话保存或设备间同步。
- 当前不支持专业照度认证、相机推算照度、色温/闪烁检测、后台连续采集及直接保存 CSV 文件。可通过系统分享接收 CSV 文本。

## 前后端接入

V51 新增种子，不修改旧 migration 或业务表。元数据与 Android 中文资源一致，重复执行不覆盖管理员状态、编辑或软删除。后台复用工具管理的详情、开关、维护、排序、推荐与软删除；使用量沿用 `/tools/light_meter/usage`，因此排行榜与各统计窗口可计入新工具。没有新增测量 API，也没有传感器数据或配置字段变更。
