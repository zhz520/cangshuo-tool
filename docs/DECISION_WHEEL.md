# 做个决定

## 定位

- 工具编码：`decision_wheel`
- 分类 / 模式：`LIFE` / `LOCAL`
- 排序：627
- 数据迁移：`V75__seed_decision_wheel_tool.sql`
- 分层：Compose → `DecisionWheelViewModel` → `DecisionWheelUseCases` → `DecisionWheelRepository`

通过可编辑选项和权重抽取一个随机结果，适合选择吃什么、是否答应、休息时做什么等轻量决策。随机数、选项、权重和最近结果均只保存在本机，不联网、不登录、不申请权限。

## 已实现功能

- 最多 12 个选项，每项可设置 1–10 权重；扇区大小和“基础占比”按全部选项的权重计算。
- 使用 `SecureRandom` 在符合条件的总权重区间内抽签，不让动画决定结果。
- 转盘以顶部指针为目标，先确定中签项，再计算四至六圈的停止角度；结果落在该扇区内部，固定为可重复的运动路径。
- 中央按钮点击和转盘环形拖动均可交互；旋转动画期间禁用重复触发和拖动。
- 三组本地化快捷主题：今天吃什么、是或否、现在做什么。
- 避免连续重复开关；有替代结果时排除上一次结果，再把剩余权重归一化后抽签。此时界面仍显示全量选项的“基础占比”，不会把条件概率误标成固定概率。
- 选项编辑支持新增、改名、调权重和删除；至少保留两项，禁止空值、超长、同名（含全角/大小写等价）和越界权重。
- 抽签完成后显示结果卡，并写入最近 30 条历史；历史可展开、清空，结果列表可复制或分享。
- 选项、权重、开关和历史通过 `SavedStateHandle` 恢复；退出工具再进入仍保留数据。
- 中文和英文完整资源、独立 24dp 线性图标、主题色、48dp 触控区域和无障碍状态。

## 抽签与动画规则

- 选项名称先移除控制字符、把换行/制表符压成空格、合并空白，并按 Unicode 码点和常见 emoji 簇边界限制为 24 个码点。
- 同名判断先做 NFKC 归一化，再以根区域规则忽略大小写；`ＡＰＰＬＥ` 与 `apple` 视为重复。
- 总权重在每次抽签时重新计算。排除上一结果后按剩余权重建票；不会用先随机扇区再拒绝的方式反复抽样。
- 每次转动额外追加 4–6 整圈，并随机选择中签扇区内部 22%–78% 的位置，避免每次都停在正中心。
- Compose `Animatable` 使用加速后减速的贝塞尔曲线；动画结束才写入结果，重复回调会按 spin id 去重。拖动手势与抽签共享同一旋转状态，发起抽签前会取消未完成的拖动更新；动画被取消时仍会落到计划角度并完成本次抽签。
- 完成后的规范化角度、结果卡显示状态、选项、权重与历史都写入 `SavedStateHandle`；旋转屏幕或重新进入工具后，指针与高亮扇区保持一致。
- 系统关闭动画时仍以最终结果为准；页面中途离开不会提前写入尚未停稳的结果。

## 数据与边界

- 历史最多保留 30 条，报告最多分享全部 30 条；清空历史不影响当前选项。
- 快捷主题会替换当前选项，历史保留；恢复默认前显示确认。
- 不提供多转盘管理、云端同步、多人房间、图片转盘、音效、抽后移除、概率的手动百分比输入或历史统计图表。
- 进行中的旋转动画不会跨进程恢复；进程被系统回收后，重新打开会停在最近一次已完成的规范化角度，不会提交未停稳的结果。
- 不使用系统通知、悬浮窗、前台服务、网络、相机、麦克风或其他敏感权限。
- 纯概率工具不能保证公平抽奖或用于涉及财产、资格审查等正式抽签场景。
