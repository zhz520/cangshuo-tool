# 工作性价比

## 定位

- 工具编码：`work_value`
- 分类 / 模式：`CALC` / `LOCAL`
- 排序：58
- 数据迁移：`V71__seed_work_value_tool.sql`
- 分层：Compose → `WorkValueViewModel` → `CalculateWorkValueUseCase` → `WorkValueRepository`

工具把收入、发薪月数、奖金福利、工作支出、有效工作日、每日工时和通勤一起纳入，分别计算名义时薪与真实时薪。全部在设备本地完成，没有网络、登录或额外权限。

## 计算语义

- 有效工作日 = `52 × 每周工作天数 − 每年带薪非工作日`。
- 年度总现金 = `月薪 × 每年发薪月数 + 年度奖金 + 每月现金福利 × 12`。
- 年度工作支出 = `每月工作支出 × 12`；扣除支出后的年收入允许为负，用于明确展示不划算的工作。
- 每日有效工时 = `每日在岗小时 − 每日无薪休息`。
- 年度有效工时 = 有效工作日 × 每日有效工时。
- 年度通勤小时 = 有效工作日 × (每周到岗天数 / 每周工作天数) × 单程通勤小时 × 2。
- 名义时薪 = 年度总现金 / 年度有效工时。
- 真实时薪 = 扣除工作支出后的年收入 / (年度有效工时 + 年度通勤小时)。
- 通勤占全部时间 = 年度通勤 / 全部工作与通勤时间。
- 每 100 元收入耗时 = 全部工作与通勤时间 / 年度总现金 × 100 × 60。

52 周是明确的产品近似，不根据具体年份、闰年或法定调休自动变化；用户可填写自己的“每年带薪非工作日”覆盖年假与假期。

## 已实现功能

- 月薪、发薪月数、年度奖金、每月现金福利、每月工作支出。
- 每周工作天数、每周到岗天数、每日在岗工时、无薪休息、单程通勤、每年带薪非工作日。
- 标准双休、单休、大小周、远程办公四个工时预设；预设只修改工时和通勤字段，不清空工资和福利。
- 即时显示真实时薪、名义时薪、年度总现金、年度净现金、有效工作日、有效工时、通勤小时、通勤占比和每 100 元耗时。
- 所有字段写入 `SavedStateHandle`；清空后恢复安全默认值。
- 输入长度和范围校验、非数字、无效工作日/休息、零有效工时分别反馈；本地同步计算不伪造 loading。
- 复制与分享摘要，中英文资源完整。

## 边界

- 输入金额上限为 1 万亿元，字段最多 18 个字符；只接受普通十进制数字。
- 每周工作天数 1–7，到岗天数不得大于工作天数；每日在岗 0.5–24 小时，无薪休息必须小于在岗小时；单程通勤最多 12 小时；带薪非工作日最多 365 天。
- 年为税前估算，社保、公积金、个税、股票/期权、一次性补助和报销未建模。
- 不考虑大小周具体日历、法定调休、年假使用顺序或远程日的不同通勤频率；到岗比例按全年平均。
- 不联网获取工资水平、城市 PPP 或行业基准，不做“好工作/坏工作”主观评级。
