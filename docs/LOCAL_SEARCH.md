# 本地搜索

Phase 1 的本地搜索页从首页和工具页进入。沿用当前内置 `ToolRegistry`，可以从搜索结果打开已注册工具；目前实际工具为计算器。界面提供中文和英语，默认语言规则见 [多语言说明](ANDROID_LOCALIZATION.md)。

## 实现分层

```text
SearchRoute / SearchScreen
  → SearchViewModel
  → SearchToolsUseCase
  → ToolSearchRepository / RegistryToolSearchRepository
  → ToolRegistry / 本地资源
```

搜索使用内存中的启用工具元数据及分类别名，同步执行无 I/O 的本地字符串匹配。每次输入变化立即重新搜索，不等待服务器；UI 不直接访问注册中心、数据库或网络。结果打开复用首页的 ViewModel → OpenHomeToolUseCase → Repository → Registry 检查流程。

## 匹配规则

| 项目 | 行为 |
| --- | --- |
| 输入 | 最多 80 个 UTF-16 字符；超长输入被拒绝，保留上次查询并显示提示 |
| 规范化 | 查询与字段使用 Unicode NFKC、Locale.ROOT 小写及空白折叠，支持全角英数与大小写不敏感匹配 |
| 查询字段 | 当前语言的名称、稳定编码、关键词、当前语言的说明、分类编码与中英文分类别名 |
| 多词 | 按空白拆分，所有词都必须匹配同一个工具，可分布在不同字段 |
| 空白查询 | 显示当前分类内的全部启用工具，默认分类为“全部” |
| 分类 | 13 个稳定分类；与文本查询共同筛选 |
| 排序 | 当前名称完全匹配 → 名称开头 → 名称包含 → 编码或关键词 → 说明 → 分类；同级已收藏工具优先，然后按 sortOrder、code 升序 |
| 多词排序 | 无完整名称匹配时，取各词最佳字段等级中的最低相关度等级 |

当前计算器关键词同时包含“计算器”“计算”“四则运算”“calculator”“arithmetic”，因此另一语言的工具名也可通过关键词命中。新增工具须在统一元数据的关键词中包含另一语言的名称及常用别名。13 个分类的双语别名保存在 `res/values/search_keywords.xml`，声明为不可翻译，显示名称仍由当前语言资源决定。

这里只做字面子串匹配，不包含拼音、纠错、同义词推断、远程向量检索或自然语言理解。输入不作为正则表达式执行。后续本地收藏任务已接入同级收藏优先与共享星标状态，见 [本地收藏说明](LOCAL_FAVORITES.md)；最近使用权重按对应任务接入。本地搜索没有记录搜索历史或工具使用记录。

## 页面与恢复

- 搜索页支持输入、清除查询、全部/分类筛选、结果数量、无结果提示、清除全部筛选、加载与错误重试。
- 点击结果先检查工具状态、设备能力、登录和权限，再打开已注册页面；计算器本地运行。
- 结果卡片使用共享收藏 ViewModel 的星标状态，收藏提交后按同级收藏优先重新排序；搜索 ViewModel 不直接访问 Room。
- 从工具返回先回到搜索页；关闭搜索后回到原首页或工具页。搜索条件独立于首页目录的分类条件。
- `SearchViewModel` 保存查询和分类到 `SavedStateHandle`；首页保存搜索页是否打开。配置变化、搜索页再次打开及系统保存状态的进程重建由现有状态机制处理。
- 语言变化时重新读取工具显示数据并重新搜索，查询与分类保持原值。跨语言工具名通过双语关键词检索，说明使用当前语言。
- 布局沿用首页的 2–5 列工具卡片和可滚动容器，保留软键盘 Insets；有中文/英语空结果 Compose Preview。

上述导航、输入法、恢复、语言切换与设备布局尚待运行验证。查询仅用于本地筛选及系统界面状态保存，没有日志、网络上传或业务历史存储。

## 在 Android Studio 查看

1. 打开 `android/`，执行 Gradle Sync，运行 `app`。
2. 点击首页或工具页的搜索入口，输入“计算器”、`calculator`、`arithmetic` 或分类名“计算”查找当前工具。
3. 点击结果打开计算器；返回搜索页后可继续查询、清除查询或切换分类。

以上是体验路径，尚未执行设备联调。服务端 `GET /api/v1/tools/search` 仍属于规划端点；本轮没有 API 契约、DTO、数据库迁移或依赖版本变更。
