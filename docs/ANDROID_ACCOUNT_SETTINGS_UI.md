# Android 账号与设置 UI

日期：2026-10-11。范围：用户指定的当前 Android 客户端；移除侧边抽屉，整理设置、我的与登录/资料页，接入 QQ 头像，复用主题、安全区、页面过渡与原生加载。保留原认证、同步接口与路由，不改数据库、权限或依赖版本。

## 视觉与交互

视觉来源为用户的 `app-design-10pages.html` 和十页截图。第 10 页抽屉按用户要求排除，旧 Stitch 图不再作为当前布局依据。白底、浅灰输入框、蓝色主要操作、裸线性列表图标；账号和设置内容最大宽度 560dp，文字随系统字号自然增高，弹窗和表单可滚动。

“我的”显示真实昵称、邮箱和 QQ 图片，整行进入登录或资料页。设置包含主题、语言、目录列数、启动页、真实缓存大小/确认清理、隐私、权限及诊断。设置值在正常宽度右侧显示，内容区小于 320dp 或字体缩放大于 1.3 时置于标题下方；选择弹窗提供原生单选语义。用户协议、关于和使用统计仍保留未开放提示。

页面打开/返回使用共享 `ToolboxMotion`，底栏使用 180ms 淡化，系统关闭动画时遵循 Compose 原生动画倍率；操作加载取实际状态，不添加人为延迟。缓存清理及删除账号保留确认机制，图片请求失败回退默认头像并可重试，保存失败保留输入并单独提示。

## QQ 头像

使用用户提供的 [QQ 图片地址](https://q.qlogo.cn/headimg_dl?dst_uin=14329140&spec=640&img_type=jpg)，`dst_uin` 替换为当前 QQ 号。允许 5–12 位 ASCII 数字、首位非零，拒绝拼接参数、斜杠及过长输入；可从数字 `@qq.com` 邮箱识别，也可手动填写其他 QQ 号。保存空值明确覆盖自动识别，恢复默认头像。手动设置仅按账号 ID 保存在本机，不新增服务端资料字段或云同步。

网络请求在 Repository 中执行，使用独立的无 Cookie/认证拦截器 OkHttp 客户端、不跟随重定向，5s 连接/读取与 10s 总时限。最大响应 1 MiB、图片边长最多 2048px，降采样至约 192px，内存最多缓存四张。加载过程可取消，账号或 QQ 号变化后旧结果不能替换新状态；保存确认不会被随后到来的偏好 Flow 抹掉，未保存的输入也不会被覆盖。

加载头像会向腾讯发送 QQ 号和正常连接信息，页面 QQ 输入说明中明确告知。登录和退出时自动识别行为沿用用户授权的 QQ 头像需求。客户端不向头像接口转发密码或 Token。退出隐藏该账号图片与输入，保留本机该账号偏好；删除应用数据/卸载会移除本机偏好。

## 滚动、动画与主题色（2026-10-11 第二轮）

- 页面状态保留：`HomeRoute` 增加路由级 `rememberSaveableStateHolder`，列表滚动位置与页面内部状态在打开详情、搜索或子页后返回时原样恢复；工具详情页每次打开为全新状态。模拟器对比：工具库滚动后打开“设备信息”再返回，可见项 y 坐标完全一致（计算器 631、图片压缩 1516）。
- 过渡动画：`ToolboxMotion` 更新为进入 260ms 淡入 + 滑入 10% 宽度，被覆盖页 200ms 淡出 + 反向漂移 5%；返回对称，底栏切换 200ms；仍遵循系统动画时长缩放。
- 主题色：设置新增「主题色」，可选蓝（默认）/ 青绿 / 紫 / 橙 / 玫红 / 黑；强调色的容器与深色变体按亮度计算，保持原有层级（黑色在深色主题下使用近白强调色，保证可见）。选择弹窗的色点随深浅色切换明暗。该设置仅保存在本机（`accent.preferences`），不进入云同步白名单，也不改变服务端契约。
- 弹窗语言：修复应用内切换语言后弹窗仍显示系统语言的问题——`MainActivity` 现在同时本地化 Activity 级资源，弹窗与页面语言一致（主题、主题色弹窗已实测为中文）。
- 常用工具对齐：快捷工具取注册表前 8 个（手机上正好两行 4 个），保持与工具库一致的 4 列节奏；数量不足时只把最后一行居中。
- 底部首页图标：重画 `ic_home` 为等宽房屋（墙体与屋顶衔接、底部圆角），修复旧图标窄高的观感。
- 账号资料页：头部收紧为头像 + 昵称 / 邮箱；「资料」与「QQ 头像」改为输入框 + 右侧紧凑保存按钮，状态文字单独一行左对齐；退出登录与删除账号并排展示。
