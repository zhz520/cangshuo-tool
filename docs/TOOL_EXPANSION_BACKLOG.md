# 工具箱功能扩展总清单（截图功能入库）

来源：用户提供的 15 张 App 截图（2026-10-11），共 16 类 317 项功能。本文档作为长期任务清单，逐项登记开发状态、实现形态与参考开源项目。

开发约定（依据 AGENTS.md 与 docs/TOOL_DEVELOPMENT_GUIDE.md）：

- 每个功能开工前先检索 GitHub 同类实现（本文档已给出起点项目），在实际实现 PR 对应的工具文档中记录参考仓库链接、查阅日期、适配差异与验证范围。
- 状态标记：✅ 已上线（含线上验证）/ ◐ 部分已有（能力已覆盖但需扩展或独立入口）/ ✗ 待开发。
- 实现形态四类：
  - **A 本地**：Android 纯本地计算/传感器/系统能力，离线可用，元数据注册 ToolRegistry。
  - **W 网页版**：依赖重或体积大的（媒体处理、AI 图像、复杂解析）放官网 `/tools/<tool_code>/`，App 用内置 WebView 打开（Decision 019）。
  - **S 服务端 API**：需要聚合第三方数据（天气、金价、热榜、查询类），由 Server 代理并缓存，管理员后台可配置开关与数据源。
  - **M 混合**：本地为主、联网增强（如 AI 文案走 aitext 通道）。
- 前后端同步：每批新增工具需同步 ① Android 端页面与注册 ② Server 工具目录 seed（Flyway migration）③ 后台工具管理页可用（已有）。任何联网功能必须在后台可配置。

## 批次规划（按依赖与价值排序）

- **Wave 1 纯本地轻工具**（无权限、无网络，快速上线）：计算类补齐（复利/房贷/油耗/BMI/颜色/进制/日期/亲戚称呼/评分）、文字类本地项（拼音/简繁/摩斯/特殊字符/数字转中文/字数/分词/相似性/网址提取/密码生成）、图片基础处理（滤镜/拼接/九宫格/格式转换/水印/圆角/模糊/尺寸/镜像/马赛克/纯色图/取色器/Base64）、检测类扩展（坏点/触摸/色彩/灰度/白平衡）、便捷类扩展（手电筒/镜子/放大镜/补光灯/噪音/振动/海拔/提词器）。
- **Wave 2 系统能力与本地应用**：待办、习惯打卡、纪念日、番茄专注、物品资产、订阅管理、白噪音、做个决定、经期记录、万能启动、保险柜、通知自己、电子木鱼、抛硬币、答案之书、手速/反应力/帧率/色盲/MBTI 测试、应用管理、文件类（重复文件/相似图片/空文件/安装包/重命名）、提取系统壁纸、扬声器除尘、手机退水、画板、计时器、防晕车、来电模拟、强制横屏、指尖轮盘。
- **Wave 3 服务端聚合（查询/内容/热榜）**：即时热榜、60 秒早报、全网搜索、新闻资讯、金价/油价/股票/天气/台风/地震、快递/车牌/归属地/身份证/邮编/区号/高校/成语/康熙字典等全部查询类、内容类（壁纸/一言/英语/历史今日/辟谣/星座）。
- **Wave 4 媒体与文档处理**：媒体 16 项（FFmpeg 系，网页版 wffmpeg 优先）、文档 OCR 与转换（OCR/表格识别/手写识别/文档矫正/去手纹/Word 转 Markdown 等）、语音转文本、文本转语音。
- **Wave 5 AI 图像（智能应用 16 项）**：去水印/去背景/清晰化/上色/放大/去雾/去噪/去摩尔纹/风格转换/盲水印等，服务端 AI 队列或网页版工具，明确算力与成本开关。
- **Wave 6 平台解析与下载**：万能解析（首个已上线，见 [短视频解析](SHORT_VIDEO_PARSE.md)）、全能下载器、资源嗅探、主页解析、作品提取、小红书提取、优惠券领取等（依赖第三方站点，需域名白名单与合规声明，优先网页版）。

## 与现有路线图的关系

- 本清单不改变既有 Phase 1-8 的完成状态；新功能按 Wave 1→6 顺序逐步落地，每批完成后更新本文档状态列与 ROADMAP Phase 9 条目。

- 所有联网与 AI 功能必须通过 Server 代理并支持后台开关；网页版工具遵守 Decision 019（唯一 code、ToolRegistry 元数据、域名白名单、离线/错误状态）。
