# Android 用户反馈

2026-10-06 接入既有 `POST /feedback` 与 `GET /feedback/my`。登录用户在「我的 → 用户反馈」填写问题/建议/其他、正文及可选联系方式，查看最近 50 条反馈、处理状态与管理员回复。不变更服务端 API、数据库与 Android 权限。

分层为 Compose → FeedbackViewModel → FeedbackUseCases → RemoteFeedbackRepository → Retrofit，复用受限 API 网络构建器，单响应 ≤256 KiB，有限连接/读取/调用超时、无自动连接重试和无重定向。401 只刷新一次；读写前后核对账号，切换/退出账号取消任务并清空反馈、正文、联系方式，generation 防止旧任务更新新用户状态；草稿仅存内存，不持久化。

正文 1–2000 字符，允许换行，拒绝其余控制字符；联系方式 ≤128 字符单行，提交前修剪外围空白。不上传附件或工具输入。数据与请求对象 toString 脱敏，正文及回复只用 Compose Text。中英提示、共享加载和主题一致；网络/限流/输入/登录/服务错误有对应文案。

提交因网络断开而失败时不能确定服务器是否已保存，显示“先刷新列表确认是否已提交”，不自动重试 POST，避免自动制造重复反馈。成功后只清空正文和联系方式，并将服务器实际返回条目置于列表首位。

新增 6 项测试覆盖输入、段落/空联系、日志脱敏、单次 401 刷新、账号隔离、网络歧义不自动重试。Android 199 项测试、assembleDebug/lintDebug 在 2 分 17 秒通过。设备界面、服务器实际回复联调和生命周期验收按用户要求延期。
