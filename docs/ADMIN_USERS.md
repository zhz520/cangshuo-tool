# 用户管理（User management）

2026-10-05，Phase 5 第五项 User management。管理员可以搜索账号、查看资料与同步数据规模、查看登录会话，并启用/停用账号；停用会立即撤销该用户的全部刷新会话。本项没有数据库结构变更：复用 V18 `sys_user`、V19 `auth_refresh_session` 与 V20 `user_sync_entity`。

## 接口

全部位于 `/api/v1/admin/users`，需要管理员 Bearer JWT；普通用户令牌返回 403/10005。

| 方法与路径 | 说明 |
| --- | --- |
| `GET` | 分页列表；`page`（1..2147483647）、`pageSize`（1..100）、可选 `keyword`（≤128 字符，匹配邮箱或昵称）、`enabled` 布尔过滤 |
| `GET /{id}` | 单个账号资料，含未删除的收藏/最近条目计数 |
| `PATCH /{id}/status` | `{"enabled": true|false}`；停用时同事务外撤销全部未撤销刷新会话 |
| `GET /{id}/sessions` | 最近 20 条刷新会话：`sessionId`、掩码后的会话码（前 8 位 + …）、创建/到期/撤销/最近活跃时间 |
| `GET /{id}/sync?limit=20` | 同步条目键（`entityType`、`entityKey`、`updatedAtMs`、`deleted`），`limit` 1..50 |

## 边界与隐私

- 只返回账号元数据与同步条目的键；**不返回**同步 `payload_json`、密码哈希、刷新令牌哈希、完整会话码或任何工具输入内容。会话码只显示前 8 位，避免掩码值可用于会话劫持。
- 路径 id 必须是正整数：非数字、0 或负数返回 400/10001；不存在的账号返回 404/10006。`keyword` 超长或含控制字符返回 400/10001；`limit` 越界由参数校验返回 400/10001。
- 状态更新是幂等的：当账号已处于目标状态时不写审计、不撤销会话，直接返回当前资料。
- 停用流程：`sys_user.status = 0` 后撤销该用户所有未撤销的刷新会话；由于会话转换器会校验 `sid` 是否仍然活跃，已签发的访问令牌也立即失效，无需等待 15 分钟过期。
- 列表按 `id DESC`（新账号在前）排序，避免大表排序成本；计数使用子查询，只统计 `deleted = 0` 的条目。

## 审计

启用/停用通过 `AdminAuditService` 写入 `admin_operation_log`：`module='user'`，操作 `STATUS_ENABLED`/`STATUS_DISABLED`，结果 `SUCCESS`。查询接口不写审计。

## 后台页面

`admin/src/views/UsersView.vue`（导航“用户管理”）：关键词与状态筛选、分页表格（ID、邮箱、昵称、状态、收藏/最近计数、最后登录、注册时间）、详情对话框（资料、最近 20 条会话、20 条同步条目）与启用/停用操作。停用前弹窗明确提示会立即撤销全部登录会话。`admin/src/api/users.ts` 严格校验响应结构。
