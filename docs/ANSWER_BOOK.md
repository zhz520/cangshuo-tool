## 具体源码参考（2026-10-20）

实际查阅 MIT [vikiboss/60s 的 answer.module.ts](https://github.com/vikiboss/60s/blob/d582aa65d44f76e91c434174c9cf44684d30755f/src/modules/answer/answer.module.ts) 与 [common.ts](https://github.com/vikiboss/60s/blob/d582aa65d44f76e91c434174c9cf44684d30755f/src/common.ts)，固定提交 `d582aa65d44f76e91c434174c9cf44684d30755f`；核查根目录 `license` 为 MIT。

采用随机选择一个条目、稳定条目编号、文本/结构化展示的思路。上游按传入 ID 或 `Math.random()` 选取答案，本工具以 SecureRandom 选取当前主题未抽过的条目，抽完开始新一轮；数据与状态保存在设备，页面没有调用上游 API。未复制代码、答案库或图片；60 条中英灵感语句为本项目新写，不转录原版出版物。

## 功能

- 全部 60 条、向前一步/慢一点/换个角度各 20 条；中英用稳定 ID 一一对应，切换语言展示相同页的翻译。
- 每个主题有独立已抽集合；一轮内抽完前不重复，轮次结束后的第一条避开刚才最后一条；不同主题池有重合，切换主题可能遇到同一句，不宣称全局去重或任何“预测准确率”。
- 每次翻阅同时保存历史与抽取轮次，只有写入确认后更新显示；快速连点串行拒绝重复任务。失败保留旧答案并要求重新读取，不自动重抽冒充原结果。
- 收藏/取消收藏、最近 50 次翻阅、历史/收藏两组列表、选中旧页在上方展开、全文复制与系统分享。列表可省略长标题，选择后主区域完整展示。
- 清空历史需确认，只清历史，不清收藏、最新页或已抽进度；读取损坏时可确认重置所有本机记录来恢复。
- SharedPreferences 私有单份 JSON，IO dispatcher 与 Mutex；64KiB 输入上限，最多 50 条历史，60 个收藏，四个有界已抽集合；校验 ID、主题、时间、token 唯一性及 schema version。
- 不保存或索取用户的问题，既没有问题上传也没有智能分析。原生主题、共享按钮/加载/结果分享、轻量切页过渡、live-region 宣读新结果；完整兼容中英和深浅色。

## 边界与状态

启动加载失败与写入失败分别反馈，失败不抛原始异常到 UI；重新读取成功前不允许再抽，避免未知提交状态下重复操作。显式重置可绕过损坏 JSON 的解析并写入空状态。

进程恢复使用已持久化抽取进度；SavedState 只保留所选主题、当前阅读页与列表标签。中途杀进程不会依赖动画落定来保存结果；数据库无业务数据。随机内容仅用于娱乐与启发，不能替代事实核验或重要决定。
