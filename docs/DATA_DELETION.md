# 账号及数据删除

2026-10-06：我的 → 删除账号 → 阅读不可撤销说明 → 输入完整账号邮箱与密码 → 永久删除。只支持用户主动确认；不会根据退出登录自动删除。匿名使用无需账号。

`DELETE /api/v1/auth/me`，用户 Bearer JWT，请求 `{email,password}`，成功 HTTP 200/code=0/data=null。身份只能来自 JWT subject，忽略请求额外 id，明确拒绝管理员 Token。邮箱规范化后必须匹配当前账号，BCrypt 再验证密码；错误身份/密码 401，非法输入 400，严格认证桶限流 429。客户端最多一次 401 刷新，不在超时/断网后自动重发删除。

事务删除 sys_user 后，既有外键级联移除 auth_refresh_session/token、user_sync_state/entity、user_feedback 和 ai_daily_usage；登录与刷新立即失效。V36 仅新增 deleted_account 删除台账（旧 user_id、UTC 时间；无邮箱、密码或内容），与账号删除同一事务。旧账号 ID 不再复用，台账用于旧备份恢复后再次删除这些账号。当前普通用户没有对象上传能力；admin 的 stored_object 不属于该用户数据。

Android 按 network → writes 顺序锁住同步，等待已有传输结束，再执行删除并清理本机该账号的 sync_entry/preference，取消待同步调度。网络失败保留本机分区，避免把未确认的删除当作成功；确认成功后以 NonCancellable 清理会话与 Room 分区。数据库结构未变，新增 DAO DELETE 不需 Room migration。若服务端已删除但本机清理失败，显示错误，用户可在系统应用设置中清除存储，不宣称清理已完成。

匿名收藏/最近使用、扫码历史、其他账号分区以及用户导出的文件不会随账号删除移除。扫码历史可在二维码页删除/清空；匿名最近可在最近列表清空。要清除全部本机数据，使用 Android 系统「应用 → 沧烁工具箱 → 存储 → 清除数据」或卸载；用户保存到相册/文档的文件需在对应应用删除。其他设备副本不会被远程擦除；已删除账号不可再登录，但该设备本机副本仍需用户清理。

备份属于访问受限的恢复副本，删除请求不逐份修改不可变备份；备份最多保留 30 天（部署方需要实际设置并执行保留策略）。恢复旧备份时必须合并最新删除台账并重新清除账号，在开放服务前执行；台账应独立备份到备份故障域之外，不能只依靠旧快照自身的台账。管理员操作日志只保留操作信息；本机制不删除管理员账号或审计日志。真实上线还需确定运营主体、联系方式和备份保留责任。
