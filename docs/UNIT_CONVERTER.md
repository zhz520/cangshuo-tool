# 单位转换工具

Phase 2 首个核心工具，唯一编码 `unit_converter`，分类 `CONVERT`，模式 `LOCAL`。无需登录、网络或 Android 权限，默认启用并推荐，排序值为 100。应用入口将 `UnitConverterToolDefinition` 注册到现有 `ToolRegistry`，首页、工具列表、转换分类、搜索及推荐区使用同一份定义。

## 实现分层

```text
ConverterRoute / ConverterScreen
  → ConverterViewModel
  → ConvertUseCase
  → ConverterRepository / LocalConverterRepository
  → UnitData (12 个转换分类、88 种常用单位定义) / BigDecimal
```

转换逻辑与单位定义完全在本地运行，不请求网络 API、不保存任何用户输入数据。界面使用响应式 StateFlow 驱动，输入数值或切换单位时即时重新换算。

## 换算与计算规则

- **标准换算**：`目标数值 = 源数值 × 源因子 ÷ 目标因子`，全部使用 `BigDecimal` 与 `MathContext.DECIMAL128`（34 位有效数字）进行高精度计算。
- **温度换算**：采用标准温标换算公式，以摄氏度为中间桥梁：
  - 摄氏度与华氏度：`°F = °C × 9/5 + 32`，`°C = (°F - 32) × 5/9`
  - 摄氏度与开尔文：`K = °C + 273.15`，`°C = K - 273.15`
- **结果格式化**：使用 `stripTrailingZeros()` 清除无效末尾 0，零统一显示为 `0`。先用精度、scale 和符号估算普通十进制字符串长度；不超过 128 字符时使用普通十进制，否则使用完整科学计数法。不会先展开长字符串，也不会截断有效数字或添加省略号；显示与复制使用同一份完整结果。`1E+3` 表示 `1000`。
- **限制与边界**：输入最长 64 字符。UseCase 在换算前后都检查精度不超过 64 位、scale 在 `-1000..1000`，非零数的十进制数量级（`precision - scale - 1`）在 `-1000..1000`；零也必须通过 scale 限制。超出范围时不执行换算或结果展开，通过中英文范围提示反馈；非法语法使用数字输入提示。
- **计算边界**：标准换算仍采用 DECIMAL128 舍入规则；科学计数法保留的是换算后结果的全部有效数字，并不代表无限精度。单位与因子来自固定本地目录。

数值表示规则参考 [Java BigDecimal 官方说明](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/math/BigDecimal.html)，范围限制由本工具明确规定。

现有 `horsepower` 使用机械马力的换算因子，中文/英语均明确其含义，避免与公制马力混淆。两者的区别见 [NIST 单位换算表](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b9)。

## 页面与交互规范

- 遵循轻量本地优先原则，页面不重复展示“本地处理/无需登录”等特性宣传语。
- 分类切换采用水平滚动的 FilterChip 列表。
- 源单位与目标单位采用下拉选择菜单（ExposedDropdownMenuBox），展示符号与本地化名称。
- 居中提供“对调单位”按钮，点击互换当前实际选中的源单位与目标单位，包括初始默认单位、切换分类后的默认单位及从保存状态回退的单位；连续点击读取最新的选择 ID。
- 结果卡片支持文本选择，下方提供一键“复制结果”按钮至系统剪贴板。
- 支持深浅色主题自适应，最大内容宽度约束为 600dp，兼容软键盘 Insets。

## 后续验收建议

1. 在 Android Studio 打开 `android/`，编译运行 `:app:assembleDebug`。
2. 进入应用，在首页常用或分类“转换”中点击“单位转换”。
3. 测试各分类换算（如长度、温度、数据容量等）。
4. 测试对调单位、复制结果、非法字符输入。
5. 初次打开及切换分类后直接点击对调；快速连续点击两次应回到原顺序。
6. 验证 `1e100000000`、`1e-100000000`、`0e100000000` 返回范围错误；超大指数语法解析失败时返回无效数字提示，界面仍可编辑。
7. 同单位换算 `1e127` 使用完整普通十进制，`1e128` 和 `1e-127` 使用完整科学计数法；负号也计入普通十进制长度限制。复制后数值应与结果一致。
8. 验证 `0`、`-0.000`、普通小数、温度换算和产生超出范围结果的单位组合。
