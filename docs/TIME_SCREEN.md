# 时间屏幕

## 定位

- 工具编码：`time_screen`
- 分类 / 模式：`LIFE` / `LOCAL`
- 排序：626
- 数据迁移：`V74__seed_time_screen_tool.sql`
- 分层：Compose → `TimeScreenViewModel` → `ReadTimeScreenUseCase` → `TimeScreenRepository`

将设备变成可长时间显示的全屏数字时钟，适合桌面、柜台和床头使用。时间与设置只保存在本机和 `SavedStateHandle`，不联网、不登录、不申请额外权限。

## 已实现功能

- 实时时钟预览，默认 24 小时制并显示秒、日期和时区。
- 12 / 24 小时切换；可分别关闭秒数、日期和时区，关闭秒数后每分钟刷新一次。
- 全屏显示，隐藏系统状态栏与导航栏；返回键或退出按钮结束，离开全屏后恢复系统栏。
- 控制层进入全屏后显示，四秒无交互自动淡出；点按全屏画面可再次显示或隐藏。
- 全屏中可直接切换秒数并显示或隐藏控制。
- 防烧屏漂移开关和 2–16dp 的可调范围；以十秒步进、四分钟循环的圆周轨迹移动，动画平滑且边界固定。
- 屏幕常亮开关；设置只作用于全屏会话，退出后释放窗口常亮标志。
- 字体按可用宽高自动收缩，兼容横竖屏和较大系统字体；日期较长时最多两行并使用省略号。
- 恢复默认设置；全部显示选项通过 `SavedStateHandle` 恢复。
- 中文和英文资源、独立的 24dp 线性图标、主题颜色和无障碍描述。

## 输入与显示规则

- 时间只读取设备当前时区与系统时钟，不从网络校准，也不要求登录。
- 24 小时制使用 `HH:mm` / `HH:mm:ss`，12 小时制使用 `h:mm` / `h:mm:ss`；上午/下午文本由当前 Locale 决定。
- 日期使用系统 Locale 的完整日期格式；时区优先取当前 Locale 的短名称，没有名称时回退到时区 ID。
- 计时器始终瞄准下一整秒或整分钟，并把等待限制在 100–60,000ms，避免快速忙循环；页面离开前台时停止任务，返回时立即重算。
- 防烧屏半径限制为 2–16dp；恢复状态时再次收敛。关闭防烧屏时偏移立即回到零。
- 全屏背景在浅色主题使用 `inverseSurface`，深色主题使用 `surfaceContainerLowest`；前景优先用强调色，与背景对比度低于 3:1 时回退主题第三色。

## 边界

- 这是应用内全屏工具，不是 Android `DreamService`、锁屏替代品或后台常驻服务；息屏、切到其他应用或系统回收后不保证继续显示。
- 不支持闹钟、世界时钟、多时区并排、倒计时、闹钟铃音、亮度调节、强制横屏或息屏显示。
- 不强制使用黑色背景或固定亮度；OLED 防烧屏效果取决于设备屏幕与实际显示时长，不能承诺完全避免残影。
- 不申请系统时间设置、悬浮窗、屏幕覆盖或其他特殊权限。
