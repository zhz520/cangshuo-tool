## 开源参考

2026-10-20 实际阅读 [sopheadave/click-speed-test 的 click-speed-test.js](https://github.com/sopheadave/click-speed-test/blob/8c7d1e734a2b99fae9f421244da0ad73043d25e1/click-speed-test.js)，固定 commit `8c7d1e734a2b99fae9f421244da0ad73043d25e1`，核查 [LICENSE](https://github.com/sopheadave/click-speed-test/blob/8c7d1e734a2b99fae9f421244da0ad73043d25e1/LICENSE) 为 MIT。

阅读范围为 `startGame` 的开始/时间更新、点击监听的计数、`endGame` 的总次数除以测试时长及重试交互。采用固定时长计数与 CPS 定义；本实现从首次按下开始且计入首击，用 Android 单调 uptime 与触摸事件时间取代 `Date` 墙钟及 1ms setInterval。50ms ticker 只刷新显示，不决定点击窗口；每次输入独立检查截止点。没有复制源代码、素材、动物等级、外链分享或远程图标。

## 已实现流程

- 选择 1 / 5 / 10 / 30 / 60 秒及单指/多指模式 → 准备 → 首次按下开始 → 截止结算 → 查看逐秒统计、趋势 → 摘要/CSV 复制与系统分享。
- 单指：一次接触中只记首个按下，其他手指须全部抬起才开始下一次；多指：同一输入事件中各个新按下分别计数。长按、移动、抬起不增加次数，区域外新触点不计入。
- 支持键盘 Enter/空格/方向确认键（系统重复 KeyDown 不计）及可访问点击。输入来源以触摸/键盘/辅助/混合标注，历史触摸最佳只比较相同时长和模式的纯触摸结果。
- 显示次数、剩余/已用时间、平均 CPS、最高单秒次数和逐秒曲线。平均 CPS 最终为总次数/所选秒数；运行中分母不小于 1 秒。峰值使用从首击开始的固定一秒分组，当前秒可能未满，不宣称滚动窗口峰值。
- 最近 20 组完整成绩保存在私有 SharedPreferences；会话 ID 去重，读写 IO dispatcher 与 Mutex 串行，失败可重试，清空需要确认，清空后不会因进程恢复重新写入同一成绩。
- 中断结果可查看与导出，CSV 包含配置时长、实际耗时、模式、来源位掩码及完整标记，避免把中断数据当作完整测试。

## 时序与资源边界

- 计数区间为 `[首次按下, 首次按下 + 时长)`；截止瞬间及之后不计入，即便刷新 ticker 尚未执行。未来时间戳、倒序事件和准备前排队的旧输入不计入；多指允许相同时间戳。
- 首击前等待不限时，没有虚假倒计时。锁屏、切后台、旋转或重新测试确认会取消本次进行状态；未结束的测试不继续计时、不写完整历史。若进入后台时测试已经正常到期，则先结算完整测试。
- SavedState 恢复轮次参数和部分计数；不恢复旧时钟。已完成但保存尚未确认的会话允许幂等补写。
- 最多 60 个整数分组，10000 次上限；到上限立即标记提前结束，不保存完整成绩。历史 JSON 最大 64KiB、每条分组长度/时长/总数/来源均校验，损坏可重试或确认清空，不显示原始异常。
- 测试开始前使点击区域滚入视野，测试中不滚动且保持屏幕；按下计数无延迟动画。其他控件复用共享按钮、开关、结果行、趋势图及主题令牌，中英资源一致。

## 服务端与后台

V87 的重复执行保留管理员修改、排序、配置、状态、软删除与使用记录。工具在既有目录、后台编辑、热门排行和 7/30/90 天使用统计中可见；点击分组和历史不上传。接口 DTO/字段没有变化。

`check_tap_speed_runtime.py` 提供静态目录/双语契约和严格隔离候选验收；`verify_tap_speed_deploy.py` 仅生产 GET 与一次管理员登录，不制造生产打开次数。

## 不支持和验证

不提供自动连点、悬浮点击、云成绩、反作弊保证或人群等级。测试测量设备接收的按下事件，不是生理能力认证；不同设备及输入方法不直接比较。
