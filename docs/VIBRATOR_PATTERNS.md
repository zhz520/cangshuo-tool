# 振动器

`vibrator_patterns`，OTHER / LOCAL，排序 641，V89 目录迁移。Android 分层为 `VibratorRoute → VibratorViewModel → VibrationUseCases → VibrationHardware/LocalVibrationHistoryRepository`。仅申请普通 `VIBRATE` 权限；无运行时权限、网络、第三方依赖或 Room 表。

## 源码参考（2026-10-20）

实际阅读 MIT [LexiLabs-App/basic-haptic 的 Android Haptic.kt](https://github.com/LexiLabs-App/basic-haptic/blob/a14e6874c1f07dab63740a37179d992b9bca6849/basic-haptic/src/androidMain/kotlin/app/lexilabs/basic/haptic/Haptic.kt) 并核查 [LICENSE](https://github.com/LexiLabs-App/basic-haptic/blob/a14e6874c1f07dab63740a37179d992b9bca6849/LICENSE)，固定提交 `a14e6874c1f07dab63740a37179d992b9bca6849`。

借鉴 `vibrate(pattern)` 的统一入口、`VIBRATE` 权限标注与 API 29 前后预置效果/长时振动的兼容分层思路。本项目直接使用 Android 26+ 已稳定提供的 `VibrationEffect`，没有引入该库、复制源码或使用其预设音效；同时补上 API 31+ `VibratorManager`，并在每次播放前检查 `hasVibrator`/`hasAmplitudeControl`。

另对无许可证的简单振动测试样例只做了页面能力核对，没有使用其源码。

## 功能与参数

- 单次、双击、三连击、心跳、警报、渐强、波浪七种有限波形；所有波形一次播放，不设置无限循环。
- 单次/双击/三连击的脉冲可调 `50–2000ms`，每次按 50ms 步进；强度 `5–100%`，映射到 Android `1–255` 振幅。强度针对所有波形。
- 时间数组均以 `0` 延迟开始，振动段使用正幅度、段间间隔幅度为 `0`；每组时长与幅度数组等长，总波形限制 30 秒。
- 振动完成后记录真实开始到结束的耗时（以自动停止上限收敛），最近 20 次保存在私有 SharedPreferences；手动停止、切后台和进程恢复中断不写入“完整运行”。
- 历史包含预设、脉冲时长、请求强度、实际时长和硬件是否支持振幅；可切换摘要/CSV、复制和系统分享，清空有确认。
- 支持振幅时显示滑块并真实传幅度；仅开关的硬件不传幅度数组并明确说明强度不会影响输出；无马达直接显示不可用，不伪造成功。
- 手动停止和切后台调用 `cancel()`。恢复时若 SavedState 标记为播放中，初始化先取消系统振动并显示“已安全停止”，避免孤儿振动继续。
- 页面使用共享主题、按钮、列表、加载、结果分享和系统对话框；中英资源、深浅色、大字体及横竖屏走原生 Compose。滑块有系统原生无障碍语义。

## 边界与错误

- 参数校验拒绝范围外时长/强度；播放失败会显示硬件/系统限制提示且不进入“正在振动”。
- 历史读取、写入、清空失败分类显示并可重试。JSON 上限 32KiB、20 条，读取时校验 ID、时间、预设枚举、设置与实际长度。
- 不监听振动传感器，不提供振幅回读、频率控制或自定义 PWM；不同设备马达和外壳造成的体感差异无法在本工具内校准。
- 振动会大量耗电并可能带来触觉不适，单次波形和播放时长均有限；测试停止后释放系统振动。

## 服务端与后台

V89 只登记工具元数据，重复执行保留管理员编辑、状态、软删除和使用量。现有的目录、后台工具管理、热门排行和 7/30/90 天统计继续复用；不接收振动历史或个人设置，不新增服务端业务表或 API。
