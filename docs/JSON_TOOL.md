## 实现分层

```text
JsonRoute / JsonScreen
  → JsonViewModel
  → FormatJsonUseCase / CompressJsonUseCase / EscapeJsonUseCase / UnescapeJsonUseCase
  → JsonRepository / LocalJsonRepository
  → StrictJsonReader + JsonOutput + JsonWorkGuard
```

四个 Repository/UseCase 操作均为 suspend。统计、语法扫描、格式化、字符串转换在 `Dispatchers.Default` 执行；UI 不运行 JSON 解析、递归排版或整段 UTF-8 编码。

`StrictJsonReader` 检查结构、字符串、数字和完整根值，按原始片段输出，通过空白改写实现格式化/压缩。它不构造完整对象树，也不将数字转换为 Long、Double 或 BigDecimal。成员名只为重复键比较解码，普通字符串值验证后按原文输出。

## 功能覆盖与规则

### 格式化、压缩及语法校验

- 根节点支持对象、数组、字符串、数字、布尔值和 null。根字符串保留双引号，不再变成普通文本。
- 格式化支持 2/4 空格缩进，展开非空对象/数组；空容器保持 `{}` / `[]`。格式化生成的换行统一为 LF，不添加末尾换行。
- 压缩只移除字符串外的语法空白，不删除字符串内部空白；不是二进制压缩，也不是强制采用最短数字/转义表示的规范化。
- 原始数字、负零、指数大小写/符号、小数尾零、字符串转义写法、对象成员次序均保留。大整数和长小数不因数值转换丢失精度；大指数只是原文，不展开为巨大普通数字。
- 标准数字规则：可选负号、整数部分、小数部分和指数。拒绝前导零、缺少小数/指数数字、前导加号、十六进制、NaN 和 Infinity。
- 仅接受空格、Tab、CR、LF 作为字符串外的空白。拒绝注释、单引号、裸成员名、尾逗号、数组缺项、非小写关键字、分号分隔、多根值、BOM 和其他扩展语法。
- 空输入或仅有上述四种空白时为“尚无结果”，不是合法 JSON 通过状态；非标准空白不会先被 trim 掉而隐藏。
- 重复键不静默覆盖：全部成员仍按原次序输出，显示重复键的额外出现次数。按同一对象中解码后的精确字符串判断，因此 `"a"` 与 `"\u0061"` 是重复键；区分大小写，不做 Unicode 归一化。不同对象分别计数。
- 语法检查不验证 JSON Schema、业务字段或数字在其他程序中的可表示范围；重复键仍可能被其他软件按不同规则解释。

### 转义与反转义

| 操作/选项 | 输入与输出 |
| --- | --- |
| 转义 | 普通文本 → 带外围双引号的完整 JSON 字符串。对引号、反斜杠和 U+0000–U+001F 控制字符转义；空文本输出 `""` |
| 反转义：完整字符串（默认） | 读取一个带双引号的 JSON 字符串，允许外围四种 JSON 空白；输出解码后的文本。拒绝对象、数组、数字及根值后的多余内容 |
| 反转义：转义内容 | 不带外围引号的 JSON 字符串内容 → 普通文本。首尾空白不 trim，空内容成功输出空文本；未转义的引号、实际换行和控制字符无效 |

反转义支持 `\"`、`\\`、`\/`、`\b`、`\f`、`\n`、`\r`、`\t`、`\uXXXX`。Unicode 转义必须恰好包含四位 ASCII 十六进制数字；不支持 `\xNN`、`\u{...}`、八进制、孤立反斜杠或未知转义，不会悄悄删除它们的反斜杠。

合法代理对保持完整，可处理非 BMP 字符。原始输入中的代理对和转义解码后的代理对均检查有效性，拒绝孤立高/低代理字符。这是一项 Unicode 互通限制：RFC 的字符串 ABNF 能容纳某些孤立转义代理值，当前工具选择报错，不能把这项额外限制描述为全部来自 JSON 语法。

转义不解析输入本身是否为 JSON；例如对象源码会成为一个 JSON 字符串。反转义也不把还原结果继续当作 JSON 格式化。转义生成 JSON 字符串，没有 HTML/script 安全编码、URI 编码或其他语言的字符串编码承诺。

“结果作为输入”回填完整输出：格式化/压缩保持当前模式；转义切到反转义的完整字符串模式；反转义切到转义。它不是保留旧输入的双向交换，合法空结果也可回填。示例按钮按当前模式/字符串选项加载相应内容；示例未在本轮实际执行。

## 资源、统计与错误边界

| 项目 | 策略 |
| --- | --- |
| 输入/完整输出 | 各最多 200,000 个 UTF-16 单元；执行入口和每次输出追加前检查，不返回省略或半成品 |
| 嵌套 | 对象/数组最多 64 层，进入下一层前检查；有界递归，不承诺任意深度 |
| 结构数量 | 值（含容器）与成员名合计最多 50,000 项；普通文本转义/反转义不使用此结构计数 |
| 时间 | 每次 Repository 取得互斥锁后使用 2 秒协作执行预算 |
| 结果预览 | 最多前 8,000 个 UTF-16 单元，边界不拆代理对；明确显示预览限制，复制和回填始终使用完整输出 |
| 字节/行统计 | 后台按有效码点累加 UTF-8 字节，不生成整个 ByteArray；行识别 CRLF/CR/LF，保留末尾空行，空文本 0 行 |
| 错误位置 | 有位置的语法/Unicode/深度/数量错误显示从 1 开始的行列；列按原始 UTF-16 单元计数，CRLF 为一个换行，不显示原文片段 |

超过编辑上限的粘贴/编辑不被采用，并给出提示；原先已接受输入及其对应结果仍有效。已接受的输入或选项一旦变化，旧输出立即失效。格式化缩进、控制字符转义等可能使合法输入的输出超限，工具报错；改用压缩或减少内容，而非截断后继续复制。

错误行列在失败后的有限扫描中计算，仍检查取消；执行预算、内存或输出上限错误可能没有精确原文位置。预算是协作检查，不是硬实时期限；一次 StringBuilder 扩容、字符串/集合操作等同步步骤可能先完成才进入下个检查点。

编辑器统计的“长度”使用 UTF-16 单元，不等于用户可见字形簇数量。输入 Unicode 无效或任务未完成时可能暂时没有字节数；页面明确显示“尚未生成”。解码结果中的实际控制字符按文本保留，显示与剪贴板表现待设备验收。

## 并发、状态与界面

- 编辑后防抖 150 ms，选项变化立即发起新处理。ViewModel 跟踪 Job 和请求版本；旧任务取消或完成后不能覆盖新输入。
- Repository 用互斥锁串行处理，循环、递归入口和输出追加检查取消/预算。用户可取消、修改输入或重新处理；取消不作为原始异常显示。
- 失败清除可用结果，成功空结果与“尚无结果”分开；复制按钮使用完整输出。没有新增文件导入/导出、分享、历史、树视图、折叠、语法高亮或 Schema 检查。
- 输入、模式、缩进和反转义类型使用 SavedStateHandle 恢复；输出重新计算，恢复时超长输入被拒绝，不静默截断。SavedState 不是加密存储，不声称支持保存敏感文本。
- 不上传或记录原文、错误片段或原始异常；仅把错误类型和行列映射为中文/英语资源。
- 默认跟随系统，中文回退、英语同步；使用共享 Material 3 主题、600dp 最大宽度、键盘 Insets、可滚动卡片和 `ToolboxLoadingState`。
- 更新了中英文 Compose Preview 定义；没有实际渲染 Preview 或执行字体缩放、深色、TalkBack、键盘/剪贴板验收。
