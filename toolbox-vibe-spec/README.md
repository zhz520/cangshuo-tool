# 沧烁工具箱 — Vibe Coding Spec Pack

这套文档用于直接启动 AI Coding Agent 开发。

- `PROJECT_SPEC.md`：完整项目设计、产品需求、架构、数据库、API、安全、测试和验收标准。
- `ROADMAP.md`：按 Milestone/Phase 拆分的开发路线。
- `AGENTS.md`：AI 编码代理必须遵守的项目规则。

建议启动顺序：

1. 将这三个文件放进仓库根目录。
2. 让 Agent 先读取全部规范并进行仓库侦察。
3. 从 Phase 0 开始，每次只执行一个小任务。
4. 每个任务完成后执行测试、构建并更新 ROADMAP。
